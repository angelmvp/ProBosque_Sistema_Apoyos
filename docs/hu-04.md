# HU-04 · Crear solicitud de apoyo

La persona solicitante puede iniciar un borrador para los programas habilitados en línea,
seleccionar municipio, capturar el formato FO-PB-501A y guardar avances sin enviar.

## Criterios

- **HU-04-CA-1:** un borrador conserva programa, municipio y datos parciales.
- **HU-04-CA-2:** los campos con validación definida rechazan CURP, correo, código postal y teléfonos inválidos.

Los campos cuya interpretación no está definida en el formato se mantienen documentados como
“por confirmar”.
