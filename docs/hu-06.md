# HU-06 · Enviar solicitud

La persona solicitante revisa el resumen, acepta el aviso de privacidad y envía la solicitud.
Después del envío el borrador queda congelado para la persona solicitante.

## Criterios

- **HU-06-CA-1:** una solicitud enviada registra fecha/hora de Ciudad de México.
- **HU-06-CA-2:** no se puede enviar mientras falten requisitos obligatorios.
