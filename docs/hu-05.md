# HU-05 · Documentos de identidad y representación

El paso 3 del asistente muestra requisitos numerados de acuerdo con FO-PB-501-A. Cada documento se carga al seleccionarlo y queda ligado a la solicitud; mientras el estado sea borrador se puede reemplazar o quitar. Se muestran nombre, tamaño, estado y observación.

| Núm. | Requisito | Aplicación |
|---|---|---|
| 1 | Identificación oficial vigente con fotografía | Obligatorio para toda persona. Si no incluye domicilio, adjuntar comprobante de máximo tres meses según el formato. |
| 2 | CURP actualizada | Obligatorio para toda persona. |
| 6 | Acta vigente de elección de órganos de representación o credenciales vigentes del RAN | Obligatorio para núcleo agrario. |
| 7 | Constitución protocolizada de persona jurídica colectiva | Obligatorio para sociedad. |
| 8 | Documento vigente de representación legal | Se muestra como “si aplica”; no bloquea el envío. |

El documento 3 (FO-PB-502) se completa en línea y no se adjunta. Los requisitos que no aplican se muestran atenuados y no cuentan en el checklist. Estados: cargado, pendiente, no aplicable, subiendo y observación de revisión.

Los archivos de solicitud aceptan **PDF, JPG y PNG**, con máximo configurable de **10 MB** (`TAMANO_MAXIMO_DOCUMENTO_MB`). El servidor valida extensión y firma del contenido; DOCX y XLSX no se aceptan en solicitudes (siguen disponibles para publicaciones). El archivo puede abrirse/descargarse desde el enlace del requisito.

**HU-05-CA-1:** los documentos recibidos se enlazan y reflejan como cargados.
**HU-05-CA-2:** formatos inválidos y archivos grandes se rechazan con una explicación.
