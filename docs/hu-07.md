# HU-07 · Recepción regional

La delegación consulta exclusivamente solicitudes de su región, marca faltantes o recibe una
solicitud completa. La recepción asigna un consecutivo anual de cinco dígitos y permite descargar
un acuse PDF inmutable.

## Criterios

- **HU-07-CA-1:** una delegación no puede consultar ni recibir solicitudes de otra región.
- **HU-07-CA-2:** una recepción completa genera folio, expediente y acuse; con faltantes conserva el estado `con_faltantes`.

El formato del folio fue confirmado para este sprint como consecutivo anual simple; queda sujeto a
validación operativa si PROBOSQUE define una nomenclatura adicional.
