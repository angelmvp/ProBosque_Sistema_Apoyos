# HU-05 · Completar documentación

La persona solicitante captura FO-PB-502 y adjunta los requisitos en PDF, JPG o PNG.
El registro 502 se marca automáticamente como entregado al completar sus datos.

## Criterios

- **HU-05-CA-1:** el checklist muestra requisitos entregados y faltantes.
- **HU-05-CA-2:** una solicitud incompleta puede guardarse, pero no enviarse.
